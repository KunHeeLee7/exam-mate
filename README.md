# Exam Mate — 우리학원 시험 도우미

수능 영어 문제지, 정답표, 학생 OMR 응답을 업로드해 채점하고 성적을 분석하는 웹서비스입니다.

- 학번 및 이름: 202234914 이건희
- 배포 URL: 배포 후 기입

## 실행

Python 3.14 환경에서 개발했습니다.

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

`.env.example`을 참고해 `.env`에 `OPENAI_API_KEY`를 설정합니다. `OPENAI_MODEL`로 사용할 모델을 지정할 수 있으며 기본값은 `gpt-4.1-mini`입니다. API 키는 Git에 올리지 않습니다.

## 입력 및 기능

1. 소개 페이지에서 시험 분석 페이지로 이동합니다.
2. 동일 시험·유형의 문제지 PDF, 정답·배점 PDF, OMR Excel을 업로드합니다.
3. 분석 시작을 누르면 정답표에서 문항·정답·배점을 추출하고 채점합니다. 정답을 코드나 사전 파일에 저장하지 않습니다.
4. 결과 Excel에는 전체 성적 통계, 학생별 점수와 문항별 O/X, 문항별 분석, 학생 응답을 담습니다.
5. 챗봇으로 평균·중앙값, 최저점 학생, 특정 학생 점수를 조회하거나 최다 오답 문항의 유사 문제를 생성합니다.

OMR Excel의 첫 시트는 `학생명`(또는 학생번호)과 `Q01`~`Q45` 열을 포함해야 합니다. 응답은 1~5이며 빈칸과 0은 미응답으로 채점합니다. 학생 수는 고정하지 않습니다. 학생 번호는 행 번호가 아니라 업로드된 식별자입니다.

표준편차는 업로드된 학생 전체를 모집단으로 계산합니다(ddof=0). 최저점 동점 학생은 모두 반환합니다. 오답 상위 3개는 오답 수 내림차순, 문항 번호 오름차순으로 정합니다. 유사 문제 생성 시 최다 오답 동률은 안내하고 가장 작은 번호를 선택합니다.

## 구조와 기술 선택

- `app.py`, `views/`: Streamlit의 페이지 연결과 화면
- `services/`: PDF 파싱, 응답 읽기, 채점, 통계, Excel 생성
- `agent/`: LLM 호출, 허용된 조회 도구, 시스템 지침
- `core/`: 데이터 구조, 설정, 세션 관리
- `tests/`: 배점·미응답·동점 처리 등 핵심 계산 검증

Streamlit은 파일 업로드, 채팅, 다운로드, 배포를 한 앱으로 구성하기 위해 사용했습니다. pandas와 openpyxl로 성적을 계산하고 Excel을 생성합니다. pypdf는 업로드한 PDF의 텍스트를 추출합니다.

성적은 구조화된 데이터이며 문항 번호로 원문을 직접 찾을 수 있어 임베딩과 벡터 검색을 사용하지 않았습니다. 공유 지문 범위를 인식해 연결 문항과 함께 보관합니다. 현재 흐름은 단순한 조회 도구 호출로 충분하므로 LangGraph를 추가하지 않았습니다.

LLM은 OpenAI SDK로 호출합니다. 성적 계산은 Python 코드가 담당하고 LLM은 허용된 도구 결과를 설명합니다. 자료에 없는 출석 등은 추측하지 않도록 지시합니다. 내부 정보 요청 필터와 시스템 지침을 적용하고, 임의 코드 실행·외부 파일 접근 도구는 제공하지 않습니다. 프롬프트 인젝션을 완전히 차단한다고 보장하지는 않습니다.

학생 데이터와 대화는 세션에 저장하며 DB에 영구 저장하지 않습니다. 업로드 파일 변경 시 기존 결과와 대화를 초기화합니다. 채팅 시 필요한 조회 결과와 대화가 API 제공자에게 전송됩니다.

## 지원 범위

현재 텍스트 PDF 형태의 수능 영어 45문항·100점 정답표(동그라미 숫자 정답)를 지원합니다. 스캔 PDF/OCR, 다른 시험 형식, 원본 듣기 음성은 추후 확장 대상입니다. 원문 PDF의 그림은 텍스트로 추출되지 않습니다. 듣기 유사 문제는 원본 음성 대신 새 대본을 포함한 연습문제로 만듭니다.

응답 처리에는 18초 API 시간 예산과 최대 3회 호출을 적용했습니다. 네트워크와 모델 상태에 따라 평가의 20초 이내 응답을 항상 보장할 수는 없습니다.

### 유사 문제 생성 기준

원문·공유 지문과 함께 추정 단어 수·문장 수를 조회 결과로 전달합니다. LLM은 출제 능력, 지문 길이, 어휘·구문 수준, 추론 부담, 오답의 그럴듯함을 맞춰 새 문항 하나를 설계하고 검토하도록 지시받습니다. 원문 지문 길이의 85~115%를 참고 범위로 사용합니다. 이 지표는 텍스트 추출 기반 근사치이며 실제 학생 정답률에 따른 난이도 검증을 대체하지 않습니다.

문제 생성 전용 모듈(`agent/question_generator.py`)은 구조화된 JSON을 받아 지문 단어 수, 영어 선택지 5개, 정답 번호와 선택지별 해설을 코드로 검사합니다. 실패하면 전체 응답 시간 예산 내에서 한 번 수정을 요청합니다. 정답의 의미적 유일성과 실제 난이도는 자동 검사로 확정할 수 없습니다.
